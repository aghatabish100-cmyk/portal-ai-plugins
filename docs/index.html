Portal AI Plugins

GitHub Pages Plugin Docs AI Workflow Tools

This project provides AI-focused Portal workflows for developer tooling and automation. It is designed to help a coding agent set up, diagnose, search, and operate Portal-based workflows efficiently.

Repository README

Included capabilities

  • Portal CLI setup and authentication flows
  • Read-only diagnostics and service checks
  • Catalog search and service briefings
  • Action discovery and safe AI-assisted invocation
  • Workflow validation for plugin evaluation and automation
